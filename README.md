# Enigmap

An interactive map for all 315 Riddler collectibles in **Batman: Arkham Knight**, with step-by-step solutions in English and Italian.

Choose a marker, follow the solution, and mark it completed. Progress and language preferences stay in your browser; transfer progress between devices using JSON export/import. No account or backend.

Built with React, TypeScript, Vite, and Leaflet.

```sh
npm install
npm run dev
```

Open http://localhost:5173. Build with `npm run build`.
